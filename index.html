Calendar Sync

Calendar Sync is a small personal program. It runs on one computer and keeps that computer's own apps in step with their owner's Google Calendar.

What it does

  • It reads the events of every calendar shown in the owner's Google Calendar, from yesterday to 30 days ahead.
  • It finds events that overlap, so the owner can see a clash.
  • Other programs on the same computer can ask it whether a time slot is free.
  • Those programs can add their own events, for example a class timetable or a work roster. The events go into one calendar named "App Sync".

How it runs

The program runs a small web server for the other programs on that computer. It listens on 127.0.0.1 only, so nothing outside the computer can reach it. There is no remote server, no cloud service, no account and no sign-up. It is not offered to other people.
