Privacy policy

Last updated: 14 November 2026.

Calendar Sync is a personal program that runs on one computer. This policy explains what it does with calendar data.

What it reads

With the owner's permission, it reads the events of every calendar that is shown in the owner's Google Calendar, from yesterday to 30 days ahead. It also creates one calendar of its own, named "App Sync", and writes events to that calendar. It writes to no other calendar.

It asks for two permissions: "See the events on all your calendars", and "Make secondary Google calendars, and see, create, change and delete events on them".

Where the data goes

The data moves between the computer and the owner's own Google account, and nowhere else. The titles and times of events that overlap are also sent to an AI model that runs on the same computer, so that it can write a short note about the clash. That model is local, and it sends nothing out.

The program runs a small web server for the other programs on that computer. It listens on 127.0.0.1 only, so nothing outside the computer can reach it. There is no remote server, no cloud service, no database and no analytics. It sends nothing to the author or to any other person or company.

What is kept on the computer

  • The Google sign-in token, in data\token.json.
  • A copy of the events it last read, in data\schedule.json.
  • The clash notes and the id of the "App Sync" calendar, in data\state.json.

These files stay on the computer until the owner deletes them. The program sets no end date of its own.

Limited use

Calendar Sync uses the data it reads from Google only for the features described on this page. The data is not sold, not used for advertising, not used to train any model, and not given to any other person or company.

How to stop it

Delete data\token.json to stop the program from using the account. That file is only a local copy, so also open the Google Account page, go to "Third-party apps and services", and remove access to Calendar Sync. The second step is the one that revokes the permission at Google.

Who uses it

The author, on their own computer. The program is not offered to other people, and it is not available to download from this site. These pages exist so that the Google sign-in screen can link to a description and to this policy.
