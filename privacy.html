Privacy policy

Last updated: 14 November 2026.

Calendar Sync is a personal program that runs on one computer. This policy explains what it does with calendar data.

What it reads

With the owner's permission, it reads the Google Calendar events that the signed-in account can already see, for the next 30 days. It also creates and edits one calendar of its own, named "App Sync". It does not read or change any other calendar.

Where the data goes

Nowhere. The data stays on the computer that runs the program. It is written to a file in the program's own folder, so other programs on that same computer can read it. The program listens on 127.0.0.1 only. It has no server, no database and no analytics, and it sends nothing to the author or to any third party.

Sign-in details

The Google sign-in token is stored in a file on that computer. The owner can remove it at any time by deleting the file, or by removing access in their Google Account under "Third-party apps and services".

Who uses it

The author, on their own computer. The program is not offered to other people, and it is not available to download from this site. These pages exist so that the Google sign-in screen can link to a description and to this policy.
