Privacy policy

Last updated: 14 November 2026.

Calendar Sync is a personal program that runs on one computer. This policy explains what it does with calendar data.

What it reads

With the owner's permission, it reads the events of every calendar that is shown in the owner's Google Calendar, from the last 24 hours to 30 days ahead. It also makes one calendar of its own, named "App Sync". It always reads that calendar, and it writes events only to that calendar.

It asks for two permissions: to see the calendars and events in the account, and to make its own calendars and manage the events in them.

Where the data goes

The data moves between the computer and the owner's own Google account. The titles, calendar names and times of events that overlap are also sent to an AI model, so that it can write a short note about the clash. That model runs on the same computer, unless the owner changes the setting that names it. Other programs on the computer can also send text to the same model, which turns that text into events. The other programs on that computer can also read the events and the clash notes back from the program, through the local web server described below. The data goes nowhere else off the computer.

The program runs a small web server for the other programs on that computer. It listens on 127.0.0.1 only, so nothing outside the computer can reach it. There is no remote server, no cloud service, no database and no analytics. The program sends nothing to the author, and nothing to any person, company or service other than Google and the AI model named above.

What is kept on the computer

  • The Google client file that the owner saved, in data\credentials.json.
  • The Google sign-in token, in data\token.json.
  • A copy of the events it last read, in data\schedule.json.
  • The clash notes and the id of the "App Sync" calendar, in data\state.json.

These files stay on the computer until the owner deletes them. The program sets no end date of its own.

Limited use

Calendar Sync uses the data it reads from Google only for the features described on this page. The data is not sold, not used for advertising and not used to train any model. Apart from the AI model and the other programs on the same computer, both described above, it is not given to any other person, company or service.

How to stop it

Delete data\token.json to stop the program from using the account. That file is only a local copy, so also open the Google Account page, go to "Third-party apps and services", and remove access to Calendar Sync. The second step is the one that revokes the permission at Google.

Who uses it

The author, on their own computer. The program is not offered as a service to other people, and it is not available to download from this site. These pages exist so that the Google sign-in screen can link to a description and to this policy.
